# 💎 로아 보석 최저가 검색기

> 겁화·작열 보석의 **경매장 최저가**를 한눈에 보고, 원하는 가격이 되면 **알림**으로 알려줘요!

로스트아크 공식 API로 경매장 즉시 구매 최저가를 가져와서 레벨별로 정리해 보여줘요.
목표가를 걸어두면 트레이에서 조용히 지켜보다가, 그 가격 아래로 매물이 나오면 바로 알려드려요.

---

## ✨ 주요 기능

- **레벨·종류별 최저가 표** : 겁화·작열 7~10레벨의 즉시 구매 최저가를 한 번에 보여줘요
- **시세 등락 표시** : 직전 조회보다 오르면 🔺빨강, 내리면 🔻파랑으로 표시해요 (재시작해도 이어서 비교)
- **목표가 알림** : 보석과 목표가를 등록하면, 그 가격 이하 매물이 나왔을 때 트레이 알림을 보내요
- **2단 자동 갱신** : 알림 건 보석은 10초마다, 표 전체는 1분마다 확인해요 (주기 변경 가능)
- **호출 한도 자동 보호** : 남은 API 호출 수를 보여주고, 한도에 가까워지면 알아서 잠깐 쉬어요
- **시세 기록 그래프** : 보석별 하루 최저가를 기록해서 추이를 그래프로 보여줘요
- **백그라운드 실행** : 최소화하면 트레이로 들어가서 계속 확인해요

## 🔍 정확한 최저가를 위한 처리

- 경매장 검색은 이름 **부분 일치**라서 다른 레벨이 섞여 나올 수 있어요 → 이름이 **정확히 같은** 매물만 비교해요
- 즉시 구매가가 없는 **입찰 전용 매물은 제외**해요
- 조회 중 하나라도 실패하면 그 회차는 반영하지 않아요 (일부만 바뀐 엉터리 표가 생기지 않도록)

## 🚀 사용법

### 1. API 키 발급 (최초 1회)
1. [로스트아크 개발자 센터](https://developer-lostark.game.onstove.com/)에 로그인해요
2. 클라이언트를 만들고 API 키를 발급받아요

### 2. 처음 실행
1. exe를 실행하면 API 키 입력 창이 떠요
2. 발급받은 키를 붙여넣고 **[저장]**을 눌러요

### 3. 시세 보기
- **[시세 갱신]** 버튼을 누르면 표 전체를 조회해요
- 표의 칸을 클릭하면 그 보석이 그래프와 알림 입력칸에 바로 선택돼요 (목표가 칸에 현재가가 채워져요)

### 4. 목표가 알림 걸기
1. 보석을 고르고 목표가를 입력한 뒤 **[추가/변경]**을 눌러요
2. 같은 보석에 다시 추가하면 목표가만 바뀌어요
3. 최저가가 목표가 이하로 **새로** 내려오면 알림이 한 번 와요
   - 가격이 다시 오르면 알림이 다시 준비되고, 다음에 또 내려오면 또 알려줘요

### 5. 자동 갱신
- **[자동 갱신]**을 체크하면 시작해요
- **감시** : 알림 건 보석만 확인하는 주기 (10 / 15 / 30 / 60초)
- **전체** : 표 전체를 확인하는 주기 (1 / 3 / 5분)

> 💡 창을 최소화하면 트레이로 들어가서 백그라운드에서 계속 확인해요.
> 트레이 아이콘을 더블클릭하면 다시 열 수 있어요.

## 📊 호출 한도 안내

로스트아크 API는 **분당 100회**까지 호출할 수 있어요. 상단에 `남은 호출 85/100 · 예상 분당 약 20회`처럼 표시돼요.

| 설정 예시 | 분당 호출 |
|---|---|
| 알림 2개 · 감시 10초 · 전체 1분 | 약 20회 |
| 알림 4개 · 감시 10초 · 전체 1분 | 약 32회 |
| 알림 8개 · 감시 10초 · 전체 1분 | 약 56회 |

- 예상 호출량이 한도에 가까우면 **주황색**으로 알려줘요
- 남은 호출이 거의 없으면 `⏸ 호출 한도 보호 중`이 뜨고, 초기화될 때까지 자동 갱신을 쉬어요
- 같은 API 키를 쓰는 다른 프로그램이 있으면 한도를 **나눠 써요**

> ⚠️ 아주 싼 매물은 몇 초 만에 팔리는 경우가 많아요.
> 알림은 "이 가격대 매물이 나오기 시작했다"는 신호로 보고, 목표가를 살짝 여유 있게 잡는 걸 추천해요.

## ❓ 문제 해결

| 증상 | 해결 방법 |
|---|---|
| "API 키가 유효하지 않습니다" | 트레이 아이콘 우클릭 → **[API 키 변경]**으로 다시 입력해 주세요 |
| "API 호출 한도를 초과했습니다" | 잠시 후 다시 시도해 주세요. 알림 수를 줄이거나 감시 주기를 늘리면 좋아요 |
| "서버 점검 중입니다" | 로스트아크 점검이 끝난 뒤 다시 시도해 주세요 |
| 표에 "매물 없음"이 떠요 | 즉시 구매 가능한 매물이 지금 없는 거예요 |
| 알림이 "-"로만 보여요 | 6레벨 이하 알림은 조회 대상이 아니에요. 삭제해 주세요 |
| "저장 파일이 손상되어…" 안내가 떠요 | 백업에서 자동 복구된 거예요. 손상된 원본은 `.corrupt_날짜` 파일로 남아 있어요 |

## 📁 데이터 저장 위치

모든 데이터는 exe 폴더가 아니라 아래 폴더에 저장돼요. **새 버전을 다른 폴더에 풀어도 그대로 유지**돼요.

```
%LocalAppData%\보석 최저가 검색기\
```

| 파일 | 설명 |
|---|---|
| `GemData.json` | 목표가 알림, 시세 기록, 갱신 주기 설정 |
| `GemData.json.bak` | 직전 저장본 (자동 백업) |
| `ApiKey.dat` | API 키 (Windows 계정 단위로 암호화) |

API 키는 Windows DPAPI로 암호화돼서, **같은 PC의 같은 Windows 계정**에서만 풀 수 있어요. 다른 곳으로 전송되지 않아요.

## 🛠️ 직접 빌드하기

### 개발 환경
- Visual Studio 2022
- C# / Windows Forms (.NET Framework 4.8)
- [Newtonsoft.Json](https://www.newtonsoft.com/json) (NuGet)
- [로스트아크 Open API](https://developer-lostark.game.onstove.com/)

### 빌드 순서
1. 리포지토리를 클론해요
2. NuGet 패키지 복원 (`Newtonsoft.Json`)
3. 참조 추가 확인: `System.Security`, `System.Windows.Forms.DataVisualization`
4. 빌드 후 실행

### 프로젝트 구조

```
LOSTARK_GEM_FINDER/
├── Program.cs                  # 진입점 · 객체 조립
├── Core/
│   ├── AppConstants.cs         # 상수 (보석 종류, 조회 범위, 주기, 호출 한도)
│   ├── ApiExceptions.cs        # 401 / 429 / 503 전용 예외
│   └── Interfaces.cs           # 저장소 · API · 서비스 인터페이스
├── Models/
│   └── Models.cs               # 시세, 알림, 설정, 호출 한도 상태
├── Services/
│   ├── AuctionAPI.cs           # 경매장 검색 + 호출 한도 헤더 추적
│   ├── GemPriceService.cs      # 전체/감시 갱신, 알림 판정, 시세 기록
│   ├── GemDataRepository.cs    # GemData.json 읽기/쓰기
│   ├── JsonFileStore.cs        # 원자적 저장 · 손상 파일 보관
│   └── ApiKeyStore.cs          # API 키 암호화 저장
└── Views/
    ├── MainForm.cs             # 메인 화면 (코드로만 구성)
    └── APIKeyForm.cs           # API 키 입력 창
```

보석 종류나 조회 레벨은 `Core/AppConstants.cs`의 `GemTypes`, `MIN_GEM_LEVEL`, `MAX_GEM_LEVEL`만 바꾸면 표·알림·그래프에 모두 반영돼요.
